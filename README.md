# Пульс — живая викторина

Сайт для викторины между командами с ведущим и отдельным экраном для проектора. Вопросы зачитываются вслух. Сервер определяет первое нажатие в открытом окне ответа, ведёт все таймеры и рассылает обновления через SSE.

## Как работает сервер и повторный вход

Node.js хранит название игры, комнаты и команды в памяти одного процесса. Ведущий задаёт название и пароль при создании игры. Пароль хранится на сервере в виде хеша. При создании комнаты ведущий, а при входе команда получает секретный токен. Браузер отправляет его с каждым запросом; сервер по токену возвращает прежнюю роль. Одна команда подключается с одного устройства и может нажать один раз за раунд. Названия команд в комнате уникальны без учёта регистра. Команда может сменить название или выйти из игры; выход удаляет её из комнаты. Таймеры и первое нажатие считаются только на сервере. Пока команда отвечает и ведущий выбирает дальнейшее действие, нажатия других команд закрыты, а оставшееся от 40 секунд время приёма нажатий стоит на паузе. Отсчёт возобновляется только после «Продолжить ответ».

Ведущий может завершить ответ команды до истечения 15 секунд, затем продолжить приём нажатий или завершить раунд. Во время 40-секундного приёма нажатий ведущий также может завершить раунд досрочно.

Токен сохраняется в браузере, поэтому обновление или закрытие вкладки не создаёт новую команду. При следующем открытии сайта или той же QR-ссылки команда возвращается в свою комнату. Если в одном браузере сохранено несколько команд или роль ведущего, сайт предлагает выбрать нужную. Ведущий может войти в существующую игру с любого браузера по коду и паролю через кнопку «Войти как администратор». Закрытые вкладки помечаются как отключённые, но команда остаётся в комнате.

## Запуск

```sh
npm ci
npm start
```

Откройте `http://localhost:3000`. Для разработки: `npm run dev`. Для проверки сценария: `npm test`.

## Docker

```sh
docker build -t pulse-quiz .
docker run --rm -p 3000:3000 -e PUBLIC_URL=https://quiz.example.com pulse-quiz
```

Разместите контейнер за HTTPS reverse proxy. `PUBLIC_URL` задаёт публичный адрес, который попадёт в QR-код. `PORT` по умолчанию равен `3000`. Разрешите долгие HTTP-соединения для `/api/events`; при обрыве соединения клиент переподключается и обновляет состояние опросом.

Состояние игр находится в памяти процесса. Запускайте один экземпляр сервера без балансировки между репликами. Перезапуск завершает активные игры; для их сохранения потребуется общее хранилище и координация таймеров. Повторный вход работает в том же браузере с сохранёнными данными сайта; после очистки данных браузера или с другого устройства прежняя команда не восстанавливается автоматически.
